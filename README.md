# AboutThisApp

About window for any TontooOS `.app` bundle. Run it with the
target bundle as the single argument:

Shows a fixed 340x460 card (no maximize button, minimize and close keep
working) with the centered 120px app icon, the bold localized app name and
a `Version %version%` line read from the bundle `Info.tontoo`. Every icon
is finished through CoreIcon into an Apple-style squircle with the Liquid
Glass depth effect (white/black gradient tile when the bundle ships no
icon). Title is `About %appname%` (`en_us` / `Über` in `de_de`).
